## Cómo navegar

- Empieza por el **README** de cada proyecto para el resumen ejecutivo.
- El **código** (SQL, notebooks) y los **datos** sintéticos están en cada carpeta para que el
  análisis sea reproducible.
- Los entregables visuales (Power BI `.pbix`, Tableau `.twbx`, presentaciones) se incluyen
  como archivos; los dashboards interactivos también están publicados en línea (ver enlaces
  en cada README cuando aplique).
